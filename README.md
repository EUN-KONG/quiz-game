# 🎮 퀴즈 게임 (Quiz Game)

## 📋 프로젝트 개요

**퀴즈 게임**은 사용자가 저장된 퀴즈를 풀고 점수를 얻는 대화형 CLI 게임입니다.
JSON 파일을 통해 퀴즈 데이터를 관리하며, 게임 상태를 저장/로드할 수 있습니다.

- **언어**: Python 3.8+
- **타입**: CLI (Command Line Interface)
- **데이터 저장**: JSON 파일 기반

---

## 🎯 퀴즈 주제와 선정 이유

### 주제: 🎮 리그 오브 레전드 (League of Legends)

### 선정 이유

평소 즐겨하는 롤 게임의 챔피언 정보를 퀴즈로 만들어
재미있게 학습할 수 있도록 제작하였습니다.

## ✨ 기능 목록

### 🌟 주요 기능 (Core Features)

| 기능            | 설명                                                            |
| :-------------- | :-------------------------------------------------------------- |
| **퀴즈 출제**   | 저장된 퀴즈를 순차적으로 사용자에게 출제합니다.                 |
| **정답 입력**   | 사용자가 `1~4` 사이의 번호를 선택해 입력합니다.                 |
| **정답 판정**   | 사용자가 입력한 값과 저장된 정답을 실시간으로 비교합니다.       |
| **점수 계산**   | 정답 개수를 누적 기록하고 최종 백분율을 산출합니다.             |
| **결과 표시**   | 게임 종료 후 최종 점수, 정답률(백분율), 랭크/등급을 출력합니다. |
| **데이터 저장** | 진행 중인 게임 상태를 `JSON` 파일로 안전하게 저장합니다.        |
| **데이터 로드** | 기존에 저장된 게임 상태를 불러와 이어하기를 지원합니다.         |

### 🛡️ 입력 검증 (Input Validation)

프로그램이 예기치 않게 종료되지 않도록 예외적인 입력값을 철저히 검증합니다.

- [x] **빈 입력 처리:** 공백만 입력되거나 Enter만 누를 경우 재입력을 요청합니다.
- [x] **범위 검증:** `1~4` 범위를 벗어난 숫자를 입력하면 경고 메시지를 출력합니다.
- [x] **타입 검증:** 문자가 포함된 비숫자 데이터 입력 시 오류 메시지를 안내합니다.
- [x] **KeyboardInterrupt 처리:** 게임 중 `Ctrl + C` 입력 시 진행 상황을 안전하게 마무리하고 종료합니다.
- [x] **EOFError 처리:** 입력 스트림 오류 발생 시 예외를 포착하여 안전하게 처리합니다.

### ⚙️ 예외 및 에러 처리 (Exception Handling)

데이터 손실 및 시스템 오류에 대응하여 안정적인 게임 환경을 제공합니다.

- 🔄 **파일 손상 복구:** JSON 저장 데이터가 손상된 경우 기본 퀴즈 데이터로 자동 복구합니다.
- ⚠️ **퀴즈 데이터 부재:** 로드할 퀴즈가 없는 상황을 감지하여 적절한 안내 문구를 출력합니다.
- 🛠️ **JSON 파싱 오류:** 저장 파일의 규격이 맞지 않는 에러 발생 시 예외 처리하여 프로그램 팅김을 방지합니다.

## 💾 데이터 파일 설명

state.json

### 📍 경로

```
quiz-game/state.json
```

### 🎯 역할

게임의 최고 점수와 퀴즈 데이터를 저장
프로그램 시작 시 저장된 데이터를 자동으로 불러옴
퀴즈 추가 시 데이터를 저장
게임 종료 시 데이터를 저장
JSON 파일이 손상되거나 읽기 오류가 발생한 경우 기본 퀴즈로 복구

### 📊 스키마 (JSON 구조)

```
{
  "score": 0,
  "quizzes": [
    {
      "question": "정글러가 갱킹을 안 오는 이유는?",
      "choices": [
        "바쁘다",
        "못 봤다",
        "캠핑 중이다",
        "위의 모든 것"
      ],
      "answer": 4
    }
  ]
}
```

### 📋 스키마 상세 설명

| 필드       | 타입   | 설명                    | 예시                                |
| ---------- | ------ | ----------------------- | ----------------------------------- |
| `score`    | int    | 최고 점수(맞힌 문제 수) | `0`, `3`, `5`                       |
| `quizzes`  | array  | 등록된 퀴즈 목록        | `[{...}, {...}]`                    |
| `question` | string | 퀴즈 문제               | `"정글러가 갱킹을 안 오는 이유는?"` |
| `choices`  | array  | 4개의 선택지            | `["바쁘다", "못 봤다", ...]`        |
| `answer`   | int    | 정답 번호(1~4)          | `1`, `2`, `3`, `4`                  |

### 데이터 처리

state.json이 존재하면 저장된 퀴즈와 최고 점수를 불러옵니다.
state.json이 없는 경우 기본 퀴즈 5개를 사용합니다.
JSON 파일이 손상된 경우 기본 퀴즈 5개로 복구합니다.
퀴즈 추가 시 state.json에 데이터를 저장합니다.
게임 종료 시 state.json에 데이터를 저장합니다.
최고 점수가 갱신되면 변경된 데이터를 저장합니다.
파일은 UTF-8 인코딩으로 읽고 저장합니다.
